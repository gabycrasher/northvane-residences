# Northvane Residences: real estate website concept

A fictional Kampala real estate agency, built as a design showcase.

- **Live:** https://gabycrasher.github.io/northvane-residences/
- **Signature opening:** a blueprint of a house draws itself while its dimensions tick up, the windows light up, and the blueprint lifts away like drafting paper to reveal the home (about 3 seconds, once per visit, skippable).
- **Highlights:** search by area, type and budget; listing cards with saved homes (kept on the device) and a details panel; a room-by-room walk-through; a clickable neighbourhood map; a live mortgage calculator; a viewing request form. Prices show in UGX by default (UGX 2.07B, UGX 8.9M / month) with a UGX / USD switch at an indicative rate, since higher-end Kampala homes are often quoted in dollars.
- Static HTML/CSS/JS with GSAP + ScrollTrigger (vendored). Photos from Unsplash (credited in the footer).

The agency, listings, prices, agents and reviews are invented. Forms do not send anything. The WhatsApp button contacts the designer.
